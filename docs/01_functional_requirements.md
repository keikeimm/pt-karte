# 機能要件定義書

## 1. 目的

パーソナルトレーナーが、顧客（クライアント）ごとに分かれた「ファイル」の中で、
カウンセリングシート・注意事項/免責同意書・日々のカルテを、オフライン環境でも
手書き／入力の両方で記入・閲覧できるようにする。Chromebook（Chrome）へ
PWAとしてインストールして使うことを想定する。

## 2. 対象ユーザー

- **主担当ユーザー**: パーソナルトレーナー（1名〜少数名を想定。認証機能は無く、
  端末を共有する運用は想定していない＝1端末=1事業者の利用を前提とする）
- クライアント（顧客）本人はこのアプリを直接操作しない
  （同意書へのサイン等はトレーナーが端末を渡して記入してもらう想定）

## 3. 用語定義

| 用語 | 意味 |
| --- | --- |
| クライアント | パーソナルトレーニングの顧客。基本情報（氏名・連絡先等）を持つ |
| 会員ID | クライアント登録時に自動採番される一意な識別番号（`M00001`形式） |
| カルテ | クライアントの記入日ごとの記録。体調・メニュー・測定値・手書きメモを持つ |
| チャート（chart） | 内部的なデータ単位。カウンセリングシート・注意書き・カルテはすべて「チャート」として同じ形（ページの集合）で保持される |
| ページ / タブ | チャート内の画面区切り。フォーム／自由入力／手書きのいずれかの種別を持つ |
| テンプレート | チャートの雛形定義（`counseling` / `precautions` / `karte` の3種） |
| role | テンプレートの役割。`counseling`（カウンセリングシート）と`precautions`（注意書き）はrole付きでクライアントごとに通常1件、`karte`はroleが無く記入日ごとに複数件作成される |

## 4. 機能一覧

| 機能ID | 機能名 | 概要 | 優先度 |
| --- | --- | --- | --- |
| F-01 | クライアント一覧・検索 | 登録済みクライアントを更新日時順に一覧表示し、氏名・フリガナ・会員IDで絞り込む | 必須 |
| F-02 | クライアント新規登録 | 基本情報を入力してクライアントを新規作成。会員IDを自動採番する | 必須 |
| F-03 | クライアント編集・削除 | 基本情報の編集、クライアント単位の削除（紐づくチャートも削除） | 必須 |
| F-04 | カウンセリングシート | クライアント詳細の専用ボタンから開く固定様式（目標・生活習慣・食事・運動歴・PAR-Q+医学スクリーニング・整形外科的既往）。無ければボタン押下時に自動作成 | 必須 |
| F-05 | 注意事項・免責同意書 | クライアント詳細の専用ボタンから開く固定様式（注意事項・免責/キャンセルポリシー＋署名）。無ければボタン押下時に自動作成 | 必須 |
| F-06 | カルテ作成（記入日を選択） | 「＋ カルテを作成」で記入日を選んで作成する（自動で本日付にはしない）。同じクライアントで既に使われている記入日は作成できない | 必須 |
| F-07 | カルテのタブ構成 | 各カルテは「本日の記録」（体調・睡眠・体重・体脂肪率・メモ）／「メニュー・測定記録」（表形式）／「白紙（手書き・自由記述）」の3タブ＋顧客データタブを持つ | 必須 |
| F-08 | 手書き入力 | Canvas上でペン（筆圧対応）・消しゴム・色・太さの変更、取消/やり直し、全消去。人体図/姿勢図を背景に選択可能 | 必須 |
| F-09 | ページのスキップ | 各ページに「このページを飛ばす」トグル。前後送りボタンはスキップ中のページを読み飛ばす（直接タップすれば開ける） | 必須 |
| F-10 | オフライン動作 | 初回読み込み後はネットワーク接続が無くても全機能が利用できる | 必須 |
| F-11 | PWAインストール | ホーム画面/デスクトップへのインストールに対応（`manifest.webmanifest`） | 必須 |
| F-12 | Excel書き出し | クライアント単位で基本情報・カウンセリングシート・同意書・カルテを4シートのExcel(.xlsx)として書き出す（人に渡す書類・印刷用途、読み込みは不可） | 必須 |
| F-13 | JSONバックアップ | 全データをJSONとして書き出し／読み込み（マージ or 全置換）。アプリの内部的なデータ退避・復元用 | 必須 |
| F-14 | 明示的な保存ボタン | カウンセリングシート・注意書き・カルテのいずれも、編集内容は明示的に「保存」ボタンを押すまで確定しない | 必須 |
| F-15 | 未保存の変更の確認 | 保存せずに画面を離れようとすると「保存されていない変更があります」と確認する。移動を選ぶと変更は破棄され、留まるを選ぶと編集内容を保持したまま画面に戻る | 必須 |

## 5. ユースケース

### UC-01 新規クライアント登録
1. トレーナーが一覧画面の「＋ クライアント」を押す
2. 氏名・フリガナ・生年月日・性別・利用開始日（必須）と、電話・メール・目標・
   運動歴・ケガ既往・持病/服薬/アレルギー・緊急連絡先・かかりつけ医・備考（任意）を入力する
3. 「作成」を押すと、必須項目が揃っていればクライアントが保存され、
   会員IDが自動採番された上でクライアント詳細画面に遷移する
4. 必須項目が未入力の場合はトースト通知が出て保存されない

### UC-02 カルテを記入する
1. クライアント詳細画面で「＋ カルテを作成」を押し、記入日を選ぶ
   （デフォルトは本日。過去日を選んでバックデート入力も可能）
2. 選んだ日付が同じクライアントの他のカルテで既に使われていれば
   「◯◯のカルテは既に作成されています」とトースト表示され、作成されない
3. 未使用の日付なら作成され、エディタ画面に遷移する
4. 「本日の記録」「メニュー・測定記録」「白紙（手書き・自由記述）」のタブを
   切り替えながら入力する。入力内容は画面上にはすぐ反映されるが、
   **「保存」ボタンを押すまでは保存されない**（保存待ちの間は「未保存の変更が
   あります」と表示される）
5. 「保存」を押すと保存される（記入日を他のカルテと重複する日付に変更していた
   場合は保存が拒否され、日付を直すよう促される）
6. 保存せずに「← 戻る」等で画面を離れようとすると確認ダイアログが出る。
   「移動する」を選ぶと変更は破棄され、「キャンセル」を選ぶと編集内容を
   保持したままエディタに留まる
7. 必要に応じて記入日をその場で変更できる（保存時に重複チェックされる）
8. 使わないタブは「このページを飛ばす」でスキップ設定できる

### UC-03 カウンセリングシート・注意書きの記入
1. クライアント詳細画面の「📋 カウンセリングシート」または
   「⚠️ 注意書き・同意書」ボタンを押す
2. 未作成なら自動的に作成されエディタが開く。既存なら既存のものが開く
3. 入力後は「保存」ボタンを押して確定する（未保存のまま離れようとすると
   UC-02と同様に確認が入る）
4. 注意書きの最終ページで本人に署名してもらう（手書きサインパッド）

### UC-04 Excelでの書き出し
1. クライアント詳細画面の「このクライアントを書き出す（Excel）」を押す
2. 基本情報・カウンセリングシート・同意書・カルテの4シートを持つ
   `.xlsx` ファイルがダウンロードされる（カルテシートは記入日ごとに区切られる）

### UC-05 全データのバックアップ・復元
1. クライアント一覧の「バックアップ」→「全データを書き出す」でJSONを保存
2. 別端末やサイトデータ削除後の復元は「JSONを読み込む」（マージ or 全置換）で行う

## 6. スコープ外（今回のモックでは対応しない事項）

- 複数トレーナーでのログイン認証・権限管理
- 複数端末間のリアルタイム同期（IndexedDBはこの端末のブラウザに閉じる）
- 予約管理・決済・請求機能
- Excelファイルの読み込み（Excelは書き出し専用。復元はJSONバックアップのみ）
- クライアント本人によるセルフ入力用の別画面（今回はトレーナー同席前提）
- 会員IDの手動採番・変更（自動採番のみ、編集不可）
